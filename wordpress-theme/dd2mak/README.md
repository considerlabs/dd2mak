# 시니어 정보 서비스 워드프레스 테마 (dd2mak)

`docs/site_contents.md`의 벤치마킹 분석(Senior Planet, Age UK, 서울시50플러스, 브라보 마이 라이프, AARP, 토스 시니어 UX 리서치 등)을 반영해 제작한 커스텀 워드프레스 테마입니다. 플러그인 없이 이 테마 폴더만 업로드하면 바로 시니어 정보 서비스 사이트가 구성됩니다.

## 1. 설치 방법 (카페24 워드프레스 호스팅)

**방법 A — 워드프레스 관리자에서 zip 업로드 (권장)**
1. 이 폴더(`dd2mak`)를 zip으로 압축합니다. (`dd2mak.zip`)
2. 워드프레스 관리자 로그인 → `외모(Appearance) > 테마 > 새로 추가 > 테마 업로드`
3. `dd2mak.zip` 선택 후 업로드 → 설치 → **활성화**

**방법 B — 카페24 FTP/파일관리자 업로드**
1. 카페24 FTP 계정(또는 웹호스팅 파일관리자)으로 접속합니다.
2. `wp-content/themes/` 폴더로 이동합니다.
3. `dd2mak` 폴더 전체를 업로드합니다.
4. 워드프레스 관리자 → `외모 > 테마`에서 **dd2mak** 테마를 활성화합니다.

## 2. 활성화 직후 자동으로 되는 것

테마를 활성화하면 아래가 자동 생성됩니다.
- 핵심 주제 6개 카테고리: 건강관리(`health`), 복지혜택(`welfare`), 일자리·재취업(`jobs`), 연금·재무(`finance`), 여가·배움(`leisure`), 디지털 생활(`digital`)
- "나에게 맞는 정보 찾기" 페이지 (`/info-finder/`)
- 메인 화면(홈)은 `front-page.php`가 자동 적용되어 별도 설정 없이 8블록 구성으로 노출됩니다.

## 3. 설치 후 꼭 해야 할 설정

1. **고정링크 저장**: `설정 > 고정링크`로 이동해 저장 버튼만 눌러주세요. (일자리·교육 공고 URL 구조 활성화)
2. **메뉴 만들기**: `외모 > 메뉴`에서 새 메뉴를 만들고 6개 이하로 구성한 뒤 `주 메뉴` 위치에 지정하세요. (핵심 주제 카테고리 6개를 그대로 메뉴로 추가하는 것을 권장)
3. **로고 업로드(선택)**: `외모 > 커스터마이즈 > 사이트 아이덴티티`에서 로고 업로드
4. **히어로 문구/상담 전화번호 설정**: `외모 > 커스터마이즈 > 시니어 사이트 설정`에서 아래 값을 실제 정보로 교체하세요.
   - 첫 화면 가치 제안 문구 / 보조 문구
   - 메인·보조 버튼 문구 및 링크
   - 상담 전화번호 (헤더 고정 버튼 + 하단 상담 섹션에 `tel:` 링크로 자동 반영됩니다)

## 4. 콘텐츠 작성 가이드

### 일반 글 (건강·복지·재무·여가·디지털 콘텐츠)
- `글 > 새 글 추가` → 반드시 6개 핵심 카테고리 중 하나를 선택하세요.
- 우측 **"시니어 콘텐츠 신뢰 정보"** 박스에서 최종 검수일 / 정보 출처 / 전문가 검토 여부 / 주의 문구를 입력하면 본문 상단·하단에 자동 노출됩니다. (NIA 참고: 정보 신뢰 UX)
- **인기글로 노출**하려면 글 편집 화면의 `노출설정(공개) > 이 글을 상단에 고정`을 체크하세요. 홈의 "지금 가장 많이 찾는 정보" 3개는 고정된 글을 우선 노출하고, 없으면 최신글로 대체됩니다.
- 요약(발췌문)을 직접 입력하지 않으면 본문에서 자동으로 3줄 요약을 만들어 보여줍니다.
- 본문에 `H2` 소제목을 사용하면 글 상단에 목차가 자동 생성됩니다.

### 일자리·교육 공고
- `일자리·교육 공고 > 공고 추가` (좌측 관리자 메뉴에 별도 항목으로 생깁니다)
- **"일자리·교육 상세 정보"** 박스에서 마감일 / 지역 / 활동비 / 대상 / 신청 상태 / 신청 링크 또는 신청 전화번호를 입력하세요.
- 홈의 "마감 임박 일자리·교육"은 마감일이 임박한 순으로 자동 정렬되어 3개 노출됩니다. 전체 목록은 `/jobs-edu/`에서 확인할 수 있습니다.

## 5. 쉬운 글쓰기 & AI 초안 작성 (신규)

기본 편집기 대신, 글쓰기 권한이 있는 계정이면 누구나 쓸 수 있는 단순한 폼을 별도로 제공합니다.

1. 워드프레스 관리자 좌측 메뉴에서 `글 > 쉬운 글쓰기`로 이동합니다.
2. 제목 / 카테고리 / 본문(소제목은 서식에서 "제목 2" 선택 → 자동 목차 생성) / 출처 / 최종 확인일 / 주의 문구를 입력하고 **검수 요청하기**를 누릅니다. 카테고리는 `글 > 카테고리`에 등록된 내용을 그대로 불러와 **주메뉴 선택 → 오른쪽에 해당 하위메뉴 표시** 방식의 2단계 셀렉트박스로 구성됩니다. 하위메뉴가 없는 주메뉴는 오른쪽이 자동으로 비활성화되고, 하위메뉴가 있어도 "선택 안 함"을 고르면 주메뉴로 바로 등록됩니다.
3. 제출된 글은 **작성자 권한과 무관하게 항상 "검토 대기" 상태**로 등록됩니다. 관리자 이메일로 알림이 자동 발송됩니다.
4. 검수자(편집자·관리자)가 `글 > 모든 글`에서 검토 대기 글을 열어 확인 후 **발행**을 누르면, 이미 카테고리=메뉴로 연결되어 있으므로 **별도 작업 없이 사이트 메뉴에 자동 노출**됩니다.

### AI 초안 생성 (선택)

"쉬운 글쓰기" 화면 상단에 키워드/주제를 입력하면 Claude API로 제목·본문 초안을 자동 생성해 폼에 채워줍니다.

- 사용하려면 카페24 서버의 `wp-config.php`에 아래를 추가하세요.
  ```php
  define( 'DD2MAK_ANTHROPIC_API_KEY', 'sk-ant-여기에-실제-키' );
  // 모델을 바꾸고 싶다면 (기본값: claude-sonnet-5)
  // define( 'DD2MAK_ANTHROPIC_MODEL', 'claude-sonnet-5' );
  ```
- API 키는 [console.anthropic.com](https://console.anthropic.com)에서 발급합니다. **호출마다 비용이 발생**하니 사용량을 주기적으로 확인하세요.
- AI 초안은 `edit_posts` 권한이 있는 로그인 사용자만 생성할 수 있습니다(비공개 관리자 화면이라 외부에서 임의 호출 불가).
- 복지·연금처럼 정확한 금액·기준이 필요한 내용은 AI가 숫자를 지어내지 않도록 프롬프트에서 명시적으로 차단했지만, **AI가 작성한 글은 목록에 "⚠ AI 초안" 표시가 남아** 검수자가 사실관계를 한 번 더 확인해야 함을 알 수 있습니다. 발행 전 반드시 사실 확인을 거치세요.

## 6. 파일 구성

```
dd2mak/
├── style.css              테마 정보 + 전체 스타일 (반응형, 시니어 UI 기준 반영)
├── functions.php          테마 설정 / 기본 카테고리·페이지 자동 생성
├── index.php              워드프레스 필수 폴백 템플릿
├── header.php / footer.php
├── front-page.php         홈 8블록 조립
├── template-parts/home/   히어로, 핵심주제, 인기글, 정보찾기, 일자리, 건강정보, 디지털가이드, 상담
├── single.php              일반 글 상세 (요약/목차/검수정보/관련글)
├── single-job_posting.php  일자리 공고 상세
├── archive.php / archive-job_posting.php  카테고리·공고 목록
├── page.php / page-finder.php / search.php / 404.php
├── inc/
│   ├── custom-post-types.php  일자리·교육 공고 CPT
│   ├── meta-boxes.php         검수정보 / 일자리 상세 메타박스
│   ├── customizer.php         히어로 문구 / 상담 전화번호 설정
│   ├── template-functions.php 카드·배지 렌더링 헬퍼
│   └── easy-writer.php        쉬운 글쓰기 관리자 페이지 + AI 초안 생성 + 검수 알림
└── assets/js/main.js, toc.js
```

## 7. 시니어 UX 반영 사항 요약

| 기준 | 적용 |
|---|---|
| 본문 글자 크기 18~20px | `--font-base: 19px` |
| 줄간격 1.7~1.9 | `--line-height: 1.8` |
| 버튼 높이 48px 이상 | `.btn` `min-height: 48px`, 히어로 버튼은 56px |
| 버튼 문구 | "자세히 보기" 대신 "복지 혜택 확인하기" 류 행동형 문구 (Customizer/템플릿에 기본값 적용) |
| 메뉴 6개 이하 | 메뉴 위치 라벨에 안내 문구 표기 |
| 카드 최소 정보 | 제목 + 요약 + 날짜 + 카테고리 (`dd2mak_post_card()`) |
| 본문 폭 640~760px | `--content-width: 720px` |
| 전화 상담 진입점 | 헤더 고정 버튼 + `tel:` 링크 (이미지 아님, 모바일 바로 클릭) |
| 정보 신뢰 UX | 검수일 / 출처 / 전문가 검토 배지 |

## 8. 선택 사항

- `screenshot.png`(1200×900 권장)를 테마 폴더 최상단에 추가하면 관리자 테마 목록에서 미리보기 이미지가 보입니다. 없어도 동작에는 문제없습니다.
- 실제 배포 전, 위 UI 수치는 50~70대 사용자 5~8명 사용성 테스트로 검증할 것을 권장합니다.
