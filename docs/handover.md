# 인수인계 문서 — dd2mak (시니어 정보 서비스 워드프레스 테마)

> **최신 인수인계는 `docs/handover-v2.0.md` (2026-08-17).** 이 문서는 테마 1차 세션(2026-08-12) 기록이다.

작성일: 2026-08-12
대상: 이 프로젝트를 이어받아 운영·개발할 담당자

## 1. 프로젝트 한 줄 요약

50~70대 시니어 대상 정보 서비스(건강·복지·일자리·재무·여가·디지털)를 위한 **커스텀 워드프레스 테마**. 플러그인 없이 `dd2mak.zip`만 업로드하면 카페24 워드프레스 호스팅에서 바로 동작하도록 설계됨. 현재 **카페24에 정상 설치·활성화 완료 상태**이며, 이번 세션에서 배포 후 요청사항(색상, 버튼, 글쓰기 워크플로우 등)을 반영해 최신 zip까지 재생성해 둔 상태.

## 2. 지금 당장 알아야 할 것 3가지

1. **최신 배포 파일은 `wordpress-theme/dd2mak.zip`** (36개 파일, 약 38KB). 코드를 수정할 때마다 반드시 이 zip을 재생성해야 실제 사이트에 반영됩니다. 재생성 명령:
   ```bash
   cd wordpress-theme
   rm -f dd2mak.zip
   zip -r -q dd2mak.zip dd2mak -x "*/.DS_Store" -x "dd2mak/.DS_Store"
   ```
2. **AI 초안 생성 기능은 아직 미설정 상태**입니다. 카페24 서버의 `wp-config.php`에 `define('DD2MAK_ANTHROPIC_API_KEY', 'sk-ant-...');`를 추가해야 동작합니다 (§6 참고).
3. **복지·연금 카테고리 샘플 콘텐츠의 일부 수치는 미확정**입니다 (`docs/sample-content.md`의 `[확인 필요]` 표시 부분). 발행 전 실제 기관 확인이 필요합니다.

## 4. 이번 세션 작업 이력 (시간 순)

### 4.1 최초 분석
- 기존에 완성돼 있던 테마(v1.0.0) 코드 전체를 읽고 README/기획서와 실제 구현이 일치하는지 검증.

### 4.2 코드 리뷰에서 발견해 수정한 버그
| 항목 | 파일 | 내용 |
|---|---|---|
| 타임존 버그 | `template-parts/home/jobs.php` | `date()` → `current_time()`로 교체 (마감임박 필터링이 서버 타임존이 아닌 워드프레스 사이트 타임존을 따르도록) |
| 색상 대비 부족 | `style.css` | 버튼 배경색이 WCAG AA(4.5:1) 미달 → 진한 색으로 교체 (이후 보라색 톤으로 재변경, §4.5 참고) |
| `wp_unslash()` 누락 | `inc/meta-boxes.php` | 메타박스 저장 시 작은따옴표 포함 입력값에 불필요한 백슬래시가 남던 문제 수정 |
| **`index.php` 누락** | `index.php` (신규) | **카페24 테마 설치가 "템플릿이 없습니다" 오류로 실패했던 근본 원인.** 워드프레스는 `front-page.php`가 있어도 루트에 `index.php`가 반드시 있어야 함 |

### 4.3 콘텐츠 준비
- `docs/sample-content.md`: 6개 핵심 카테고리별 샘플 글 + 일자리 공고 샘플 작성. 복지혜택·연금재무 항목은 웹 검색으로 2026년 기준 보건복지부·국민연금공단 공식 수치를 반영했으나, 임플란트/틀니 본인부담률·에너지바우처 금액은 신뢰할 만한 출처를 확정 못해 `[확인 필요]`로 남김.
- `docs/deployment-checklist.md`: 설치→설정→콘텐츠 등록→검증까지 체크리스트 문서화.

### 4.4 UI/UX 요청 반영
- **전화 상담 버튼 삭제**: 헤더 고정 버튼, 하단 상담 섹션 버튼 삭제 (하단 전화번호 텍스트 링크는 유지). 미사용 CSS(`.header-phone-btn`)와 Customizer 설정(`dd2mak_contact_button_text`)도 함께 정리.
- **모바일 햄버거 버튼 위치 고정**: flex 줄바꿈 방식 대신 `position: absolute`로 헤더 좌측 상단에 고정.

### 4.5 톤앤매너 변경
- 사용자가 제공한 참고 이미지(다른 프로젝트의 대시보드 스크린샷)의 보라색 계열을 반영. 라이트 모드는 유지.
  - `--color-primary`: 청록 `#1d5c63` → 보라 `#5b21b6`
  - `--color-accent`: 주황 `#b74e19` → 보라 `#7c3aed`
  - 배지 옅은 배경도 보라 톤(`#f1e9fe`)으로 통일
  - 새 색상 모두 WCAG AA 대비 기준(5:1 이상) 확인 후 적용

### 4.6 "쉬운 글쓰기" + AI 초안 기능 신규 개발 (`inc/easy-writer.php`)
사용자 요청: "글쓰기 → 검수 → 발행(메뉴 자동 반영)" 워크플로우 + "키워드 기반 AI 자동 작성" 필수 요건 + "글 메뉴 하위에 쉬운 글쓰기 페이지".

- 관리자 `글 > 쉬운 글쓰기` 서브메뉴 추가. 제목·카테고리·본문(리치 에디터)·출처·최종확인일·주의문구 입력.
- **제출 시 작성자 권한과 무관하게 항상 "검토 대기(pending)" 상태로 등록** → 검수자가 wp-admin에서 발행 버튼만 누르면 카테고리=메뉴 연결 구조 덕분에 자동으로 해당 메뉴에 노출.
- 제출 시 관리자 이메일로 검수 요청 알림 발송.
- **AI 초안 생성**: 키워드/주제 입력 → Claude API 호출 → 행동형 제목 + H2 구조 본문 자동 생성. 복지·재무 등 수치는 지어내지 않도록 시스템 프롬프트에서 명시적으로 차단. AI가 쓴 글은 목록에 "⚠ AI 초안" 배지가 남아 검수자가 사실확인하도록 유도.
- **카테고리 선택 UX 반복 개선**:
  1. 처음엔 6개 고정 카테고리 하드코딩 → 실제 워드프레스 카테고리(하위 포함) 동적 조회로 변경
  2. 하위 카테고리를 들여쓰기해 한 셀렉트에 표시하는 방식 → **주메뉴/하위메뉴 2단계 셀렉트박스**로 재구성 (주메뉴 선택 시 JS로 오른쪽에 해당 하위메뉴만 채움)
  3. 워드프레스 기본 "미분류(Uncategorized)" 카테고리는 주메뉴 목록에서 제외 (`get_option('default_category')` 기준으로 제외해 이름이 바뀌어도 안정적으로 동작)

## 5. 핵심 아키텍처 이해

- **카테고리 = 메뉴**: 6개 핵심 주제(건강관리/복지혜택/일자리·재취업/연금·재무/여가·배움/디지털 생활)가 워드프레스 카테고리이자 주 메뉴 항목. 글을 해당 카테고리로 발행하면 별도 작업 없이 메뉴에 노출됨. 이 구조가 "쉬운 글쓰기"의 자동 발행 요구사항을 코드 추가 없이 충족시키는 핵심 전제.
- **일자리·교육 공고**: 별도 커스텀 포스트 타입(`job_posting`, `inc/custom-post-types.php`). 마감일 기준 자동 정렬.
- **검수 정보 메타박스**(`inc/meta-boxes.php`): 일반 글에는 검수일/출처/전문가검토/주의문구, 공고에는 마감일/지역/비용/대상/신청정보를 별도 관리.
- **테마 활성화 자동화**(`functions.php`의 `dd2mak_after_switch_theme`): 활성화 시 6개 카테고리와 `/info-finder/` 페이지를 자동 생성하고 고정링크를 플러시함.

## 7. 참고: img/7.png에 대하여

세션 초반 "카테고리 하위 메뉴" 관련 톤앤매너 참고용으로 업로드됐던 이미지인데, 실제로는 전혀 다른 프로젝트("혼삶OS 관리자")의 다크모드 대시보드가 찍힌 전체 데스크톱 스크린샷이었습니다(코드 에디터, 브라우저 탭까지 함께 캡처됨). 사용자가 확인 후 "라이트 모드는 유지, 그 화면의 보라색만 참고"로 최종 지시해 색상만 반영했고, 파일 자체는 이 프로젝트와 무관하니 정리해도 무방합니다.
