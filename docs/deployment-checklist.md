# 배포 체크리스트 — 카페24 워드프레스 호스팅

`dd2mak` 테마를 카페24 워드프레스 호스팅에 실제로 올릴 때 순서대로 확인하는 체크리스트입니다. `wordpress-theme/dd2mak.zip`은 최신 소스 기준으로 재생성해 두었습니다.

## 사전 준비 (배포 전)

- [ ] 카페24 워드프레스 호스팅 신청 및 워드프레스 설치 완료 (카페24 자체 원클릭 설치 또는 수동 설치)
- [ ] 워드프레스 관리자(`/wp-admin`) 로그인 정보 확보
- [ ] 상담 전화번호, 실제 로고 이미지 준비 (없으면 사이트명 텍스트로 대체됨)
- [ ] `docs/sample-content.md`의 글 중 최소 3~5개는 발행 전 검수 완료 — 빈 카테고리가 있으면 홈 화면 해당 섹션이 통째로 숨겨집니다(의도된 동작)

## 1단계. 테마 업로드

- [ ] 워드프레스 관리자 → `외모 > 테마 > 새로 추가 > 테마 업로드`
- [ ] `wordpress-theme/dd2mak.zip` 업로드 → 설치 → **활성화**
- [ ] 활성화 직후 아래가 자동 생성됐는지 확인
  - [ ] 카테고리 6개: 건강관리 / 복지혜택 / 일자리·재취업 / 연금·재무 / 여가·배움 / 디지털 생활
  - [ ] `/info-finder/` 페이지 (나에게 맞는 정보 찾기)

## 2단계. 필수 설정

- [ ] `설정 > 고정링크`로 이동해 **저장 버튼만 클릭** (일자리·교육 공고 URL 구조 활성화 — 이 단계를 건너뛰면 `/jobs-edu/` 아카이브가 404가 됩니다)
- [ ] `외모 > 메뉴`에서 새 메뉴 생성 → 핵심 주제 6개 카테고리를 메뉴 항목으로 추가 → **주 메뉴** 위치에 지정
- [ ] `외모 > 메뉴`에서 푸터용 메뉴도 만들어 **푸터 메뉴** 위치에 지정 (선택)

## 3단계. Customizer 설정 (외모 > 커스터마이즈 > 시니어 사이트 설정)

- [ ] 첫 화면 가치 제안 문구 / 보조 문구를 실제 서비스 문구로 교체
- [ ] 메인 버튼 문구·링크, 보조 버튼 문구 확인 (기본값: 내게 맞는 정보 찾기 / 전화로 상담하기)
- [ ] **상담 전화번호를 실제 번호로 교체** — 헤더 고정 버튼과 하단 상담 섹션에 `tel:` 링크로 자동 반영됩니다. 이 값이 기본값(`1588-0000`)으로 남아있으면 실제 방문자가 잘못된 번호로 전화하게 되니 배포 전 최우선 확인 항목입니다.
- [ ] 사이트 아이덴티티에서 로고 업로드 (선택)

## 4단계. 콘텐츠 등록

- [ ] `docs/sample-content.md`의 6개 글을 각 카테고리에 맞춰 발행 (제목·본문 그대로 붙여넣고 우측 "시니어 콘텐츠 신뢰 정보" 박스 채우기)
- [ ] 복지혜택·연금재무 글은 **발행 전 실제 수치·기관 정보 검증 완료 여부 재확인**
- [ ] 인기글로 노출할 글 1~3개는 편집 화면에서 "이 글을 상단에 고정" 체크
- [ ] 일자리·교육 공고 최소 1건 이상 등록 (좌측 관리자 메뉴 `일자리·교육 공고 > 공고 추가`) — 마감일을 반드시 입력해야 "마감 임박" 섹션에 노출됨

## 5단계. 글쓰기·검수 워크플로우 설정 (신규)

- [ ] 실제 작성자용 워드프레스 계정을 `사용자 > 새로 추가`에서 만들고 역할을 **기여자** 또는 **작성자**로 지정 (역할과 무관하게 "쉬운 글쓰기"로 제출한 글은 항상 검토 대기 상태가 됩니다)
- [ ] 관리자 좌측 메뉴 `글 > 쉬운 글쓰기`가 정상적으로 보이는지 확인
- [ ] (선택) AI 초안 기능을 쓰려면 카페24 파일관리자에서 `wp-config.php`를 열어 아래 추가
  ```php
  define( 'DD2MAK_ANTHROPIC_API_KEY', 'sk-ant-실제-발급받은-키' );
  ```
  - [ ] [console.anthropic.com](https://console.anthropic.com)에서 API 키 발급 완료
  - [ ] **API 호출은 사용량만큼 비용이 청구됩니다** — 예산 담당자와 사용량 한도를 미리 협의하세요
- [ ] 테스트 글 1건을 "쉬운 글쓰기"로 제출해 관리자 이메일로 검수 요청 알림이 오는지 확인
- [ ] `글 > 모든 글`에서 검토 대기 글을 열어 **발행** 클릭 → 홈페이지 해당 카테고리 메뉴에 자동 노출되는지 확인

## 6단계. 검증 (실제 브라우저에서)

- [ ] 홈 화면 8블록이 모두 정상 노출되는지 확인 (히어로 / 핵심주제 / 인기글 / 정보찾기 / 마감임박 일자리 / 전문가검수 건강정보 / 디지털가이드 / 상담)
- [ ] 하단 상담 섹션의 전화번호를 모바일에서 눌러 실제로 전화 연결 화면이 뜨는지 확인 (`tel:` 링크 동작 확인)
- [ ] `/info-finder/`에서 나이대·지역·관심분야 선택 후 검색 결과가 뜨는지 확인
- [ ] 글 상세 페이지에서 목차(H2 기준 자동 생성)와 요약 박스가 보이는지 확인
- [ ] 모바일 화면(640px 이하)에서 햄버거 메뉴가 좌측 상단에 고정되어 정상 동작하는지 확인
- [ ] `/jobs-edu/`에서 공고 목록이 마감일 임박순으로 정렬되는지 확인
- [ ] 검색 기능(우측 상단 또는 위젯)이 정상 동작하는지 확인

## 7단계. 마무리

- [ ] `screenshot.png`(1200×900) 테마 폴더 최상단에 추가 시 관리자 테마 목록 미리보기 개선 (선택, 없어도 무방)
- [ ] 50~70대 실제 사용자 5~8명 대상 간단한 사용성 테스트 진행 권장 (README 명시 사항 — 폰트 크기·버튼 문구 등 최종 수치 검증)
- [ ] 워드프레스 자동 백업 설정 확인 (카페24 호스팅 자체 백업 기능 또는 백업 플러그인)

## 참고: 최근 코드 리뷰에서 수정된 사항

배포용 zip에는 아래 수정 사항이 이미 반영되어 있습니다.

1. **마감임박 쿼리 타임존 수정**: `template-parts/home/jobs.php`에서 서버 PHP 타임존이 아닌 워드프레스 사이트 설정 타임존(`current_time()`)을 기준으로 마감일을 필터링하도록 수정
2. **버튼 색상 대비 개선**: 주요 버튼(`--color-accent`) 배경에 흰 텍스트를 얹었을 때 WCAG AA 기준(4.5:1)에 못 미치던 문제(약 3.1:1)를 더 진한 주황색으로 조정해 해결 — 시니어 사용자의 가독성에 직접 영향
3. **메타박스 저장 시 `wp_unslash()` 누락 수정**: 지역·비용·출처 등 입력값에 작은따옴표가 포함된 경우 저장 시 불필요한 백슬래시가 남던 문제 해결
4. **`index.php` 누락 수정**: 워드프레스 테마는 `front-page.php`가 있어도 루트에 `index.php`(폴백 템플릿)가 반드시 있어야 합니다. 이 파일이 없어 카페24 테마 설치 시 "템플릿이 없습니다" 오류로 설치가 거부되던 문제를 해결했습니다.
5. **전화 상담 버튼 삭제**: 헤더 고정 전화 버튼과 하단 상담 섹션의 전화 버튼을 삭제했습니다. 하단 전화번호 텍스트 링크(`tel:`)는 유지해 클릭 시 바로 전화가 연결됩니다. 사용하지 않게 된 `.header-phone-btn` CSS와 `dd2mak_contact_button_text` Customizer 설정도 함께 정리했습니다.
6. **톤앤매너를 보라색 계열로 변경**: 라이트 모드는 유지한 채 기존 청록(`#1d5c63`)·주황(`#b74e19`) 조합을 보라색 계열(`--color-primary: #5b21b6`, `--color-accent: #7c3aed`)로 교체했습니다. 버튼·배지·링크 등 색상은 전부 CSS 변수를 통해 적용되므로 사이트 전체에 일관되게 반영됩니다. 새 색상도 WCAG AA 대비 기준(흰 텍스트 대비 5:1 이상)을 확인해 시니어 가독성 기준을 유지했습니다.
7. **모바일 햄버거 버튼 위치 고정**: flex 줄바꿈 구조에 의존하던 방식에서 `position: absolute`로 헤더 좌측 상단에 고정하는 방식으로 변경해, 화면 크기·로고 길이와 무관하게 항상 같은 위치에 표시되도록 수정했습니다.
8. **"쉬운 글쓰기" + AI 초안 기능 추가**: `글 > 쉬운 글쓰기` 관리자 페이지를 신설해 제목·카테고리·본문만으로 글을 작성할 수 있게 했고, 제출 시 역할과 무관하게 항상 검토 대기 상태로 등록되도록 해 발행 전 검수를 강제합니다. Claude API 키를 설정하면 키워드 기반 AI 초안 생성도 가능합니다(선택 기능, 비용 발생).
